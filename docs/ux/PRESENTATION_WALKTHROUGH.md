# Presentation walkthrough

Prepare a completed campaign, selected run, a development report and a replay. A synthetic noise control is appropriate for a transparent offline demonstration; a signal control tests learnability, not real market skill.

1. Research question: explain the comparison, blind decision and virtual broker.
2. Data: show actual market history and describe chronological splitting.
3. Models: describe inputs, architecture families and target meaning.
4. Training: show convergence and retained checkpoint.
5. Results: interpret paired loss confidence intervals. A negative result is legitimate.
6. Replay: reveal the next session, observe virtual equity, inspect measured facts.
7. Explainability: show measured perturbation sensitivity, not causal importance.
8. Conclusion: state the evidence and its limits.

Use stage buttons, previous/next or arrow keys (outside focused controls); full screen depends on browser support. Exit returns to the relevant detailed screen. The protected final test is never opened by presentation mode.
