# Design system

Reuse global theme tokens in `frontend/app/globals.css`. Surfaces remain neutral; teal denotes primary actions/selection. Use red/green plus explicit text for measured evidence. Every control has a label, selected navigation uses aria-current, selection controls use aria-pressed and focus remains visible. Secondary details use native disclosure, not extra modal flows.

Panels have modest borders, consistent spacing and constrained width. Compact context precedes the task. On mobile, navigation scrolls horizontally, forms stack, charts retain their readable minimum width inside a labeled scroll region. Do not force the whole document to scroll horizontally.
